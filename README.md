# 🍔 React Native Food Delivery App

A modern **food delivery mobile application** built with React Native. The project provides a user-friendly interface for discovering food, browsing restaurants or food items, viewing product details, and building a food order.

## 📱 Project Overview

The **React Native Food Delivery App** is designed to provide a simple and convenient food-ordering experience through a mobile application.

The application focuses on a clean user interface and smooth navigation, allowing users to explore available food items and interact with the application from their mobile devices.

---

## ✨ Features

* 🏠 **Home Screen** – Browse available food and featured items.
* 🍕 **Food Categories** – Explore different types of food.
* 🔍 **Food Discovery** – Find food items through the application interface.
* 🍽️ **Food Details** – View information about selected food items.
* 🛒 **Cart / Order Flow** – Add food items and manage an order.
* 👤 **User Interface** – Simple and intuitive mobile experience.
* 📱 **Responsive Mobile Design** – Designed for Android and iOS devices.
* 🧭 **Easy Navigation** – Move between different sections of the application.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have the following installed:

* [Node.js](https://nodejs.org/)
* npm
* React Native development environment
* Android Studio and/or Xcode for native device development

### 1. Clone the Repository

```bash
git clone https://github.com/Jithukrishnaa/react-native-food-delivery-app-main.git
```

### 2. Navigate to the Project

```bash
cd react-native-food-delivery-app-main
```

If the actual React Native project is inside the nested folder:

```bash
cd react-native-food-delivery-app-main
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Application

For React Native CLI:

```bash
npx react-native start
```

Then, in another terminal, run:

```bash
npx react-native run-android
```

For iOS:

```bash
npx react-native run-ios
```

> iOS development requires macOS and Xcode.
